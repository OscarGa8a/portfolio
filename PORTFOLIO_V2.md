# Portfolio v2 — alineación completa con Oscar Dev

## Plan priorizado

1. **P0 · Credibilidad y marca** — alinear identidad, oferta y copy ES/EN; retirar métricas y lenguaje no respaldado.
2. **P0 · SEO** — metadatos localizados, schema, canonical, hreflang, sitemap, robots, favicon y OG image.
3. **P0 · Accesibilidad** — semántica, navegación por teclado, foco visible, menú móvil, skip link y reduced motion.
4. **P1 · Conversión** — WhatsApp contextual, jerarquía de CTAs, proyectos orientados al problema y eventos medibles.
5. **P1 · Responsive y performance** — imágenes responsivas, formatos modernos y limpieza de assets.
6. **P1 · Mantenimiento** — pnpm único, lockfile reproducible, checks y documentación.
7. **Validación** — instalación limpia, Astro check, build, enlaces y revisión visual móvil/escritorio.

## Decisiones

- Se conserva Astro/Tailwind: la arquitectura estática sigue siendo adecuada para el alcance.
- Se usa “Oscar Dev” como marca y “Oscar García” como persona.
- La paleta se fija en `#121214`, `#EBDDCA`, `#F29A2E`, `#EB902E` y `#CE7C2B`.
- Se elimina el contador de proyectos/sectores y se conserva únicamente prueba respaldada por las fuentes.
- Se cambia “casos de éxito” por “proyectos” y se etiqueta el resultado como cualitativo.
- La analítica queda preparada, pero desactivada hasta definir proveedor, consentimiento y credenciales.

## Criterio para la siguiente iteración

No agregar métricas, testimonios, logos, disponibilidad comercial, presupuestos ni resultados de cliente sin confirmación explícita, fuente y permiso de publicación.
